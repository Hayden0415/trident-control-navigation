# 提交与评分

只需实现 `student_map.py` 中两个函数。允许 NumPy 和 Python 标准库；不要求 OpenCV、PCL 或 ROS 编程。ROS 封装、旧规划控制和验收脚本属于提供的基础设施，不要通过改它们绕过验收。

提交：

- Git 分支/commit，包含函数实现；不要提交 build、install、log、Docker tar 或大地图。
- 一份简短报告：投影和膨胀思路、坐标索引约定、复杂度、单元测试输出、完整闭环输出、至少一个自选边界案例。
- 实际使用的镜像 ID（`docker image inspect trident-control-course:2026 --format '{{.Id}}'`）与构建命令。

评分建议，总计 100 分：

| 项目 | 分值 | 验收 |
| --- | ---: | --- |
| 三维转二维 | 35 | 高度过滤、非有限值、floor、边界、重复点、非方形尺寸 |
| 二维圆盘膨胀 | 30 | 米制半径、半径 0、边界截断、多种子、不改输入、不级联 |
| 学生完整闭环 | 25 | 到达、无碰撞、正确 raw/inflated 话题、滚动窗口、障碍出现/移动/消失不残留、输入停止后停车 |
| 可复现报告 | 10 | 操作命令、结果、复杂度与自选案例 |

公开测试是最低自检集合，不是硬编码目标；教师可更换地图参数和随机输入。`--diagnostic` 只确认基础设施，不获得地图算法或学生闭环分数。
